# 기능개발목표 체크

이 레포 에이전트·작업자는 `기능개발목표.md`를 반드시 따른다. Cursor 동일 룰: `.cursor/rules/feature-goals.mdc`.

작업 전 `기능개발목표.md`를 연다. 지금 하는 항목이 리스트에 있는지 본다.

- 있으면: 끝낸 뒤 그 줄의 `[ ]`를 `[x]`로 바꾼다. 괄호에 경로를 남긴다.
- 없으면: 해당 절 또는 `+추가` 절에 `- [x] +추가 …` 한 줄을 넣고 바로 체크한다.
- 코드와 체크를 **같은 턴**에 맞춘다. 나중에 체크하겠다고 미루지 않는다.
- 「다음에 할 것」을 남은 `[ ]`에 맞게 고친다.

## 순서

위에서 아래의 `[ ]`가 다음 작업이다. 건너뛰지 않는다. V3·MQTT·Electron·F3–F13은 장 A/B/C를 고르기 전에 구현하지 않는다.
