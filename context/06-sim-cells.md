# 통합 OCS 시뮬레이션 Cell 3종

심의용 페이지. 견적 항목1~6을 서버실·운영실·셀 캐비닛에 배치. 로컬 HW 하위(코어 이중화, 링크 속도, 셀당 EGW·영상 노드 1)는 정밀조립 예시와 같은 구조로 **가정**. 공급사 사양 확정 후 갱신.

## 공통 골격

랙 R1 네트워크·보안 / R2 데이터(서버×5·스토리지·백업) / R3 DT·AI 연산(GPU×4). 운영 데스크 2 + 벽면 표시. 서버실 가정 3.4×5.4 m(18㎡), 운영실 5.0×5.4 m(27㎡). IT 부하 ≈9 kW → UPS 15 kVA↑, 항온항습기 10 kW — **둘 다 견적에 없음**. 분전반 공사도 없음. 천장 트레이 높이 가정 2.3 m.

라이선스: Network-Lock, 모듈별 1카피. 모델 학습은 외부 국가 GPU. 존 연산 서버는 합성·시나리오·추론 검증.

지침 라벨: 적합 · 사양 보완 · 기종 확인 · 기간 확인 · 범위 명시 · 금액 미구분(총액만 = 불인정 위험).
