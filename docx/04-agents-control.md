# 에이전트 · 오케스트레이터 · 명령

레거시는 수동(작업반장)이라 에이전트 구조 비교 대상이 아니다. 자동화 기본은 단일, 피지컬AI 기본은 혼합형(`MODES.dark.agentArch = 'hybrid'`). 운전 중 전환 가능. 선택은 단계별로 기억.

## 단일 (`js/agent.js`)

1초마다 모듈 6개를 **고정 순서**로 판단·즉시 실행: 물류 · 예지정비 · 품질 · 흐름 제어 · 에너지 · 차량 충전.

## 혼합형 (`js/multiagent.js`)

| 층 | 주기 | 권한 |
|---|---|---|
| 반사 | 1초 | 자재 배차 · 셀 절전 · AGV 충전 · 정지 설비 앞 투입 보류. **바로 실행** |
| 도메인 | 정비 5초 · 품질 2초 · 흐름 3초 | 제안만 |
| 순찰 보고 | 사족보행 이상 징후 | 정비·품질 제안으로 승격. 직접 실행 아님 |
| 메인 조정자 | 1초 | 안전 → 중복 정리 → 충돌 판정 → 승인 실행 |

충돌 판정: 병목 가동 중 비긴급 예지정비 대기 · 병목 근접 대기 · 정비 인력 수 한도 · 정비 필요 셀 고속 거부 · 투입 간격 20초 안 반전 금지. P1 중 예지정비·재보정 보류.

트윈 비교(시드 평균, 문서 수치): 자동화 2시간 단일 UPH 391.2 vs 혼합 400.5. 피지컬AI는 순찰을 메인에 올린 뒤 +0.5% 수준. 제안→실행 지연 평균 약 0.7–1초.

## 우선순위 (`orchestrator.js` PRIORITY)

| P | 대상 | 처리 |
|---|---|---|
| 1 | 연기, 안전구역 사람, 비상/보호정지 | 판단 지연 25%(피지컬AI 0.4초), 자원 선점 |
| 2 | 누유, 이물질 | 지연 50%, 생산보다 먼저 |
| 3 | 설비 고장 | 정비 요청 최우선 |
| 4 | 공급 차질, 결품, 운영 명령 | — |
| 5 | 예지정비, 재보정, 편차 | P1 중 배정 보류 |

대응: 대기 정비 휴머노이드(가까운 순) → 더 낮은 P 작업 중 휴머노이드. 같거나 높은 P는 안 건드림. 없으면 3초마다 재배정. 선점 작업은 진행률 유지 후 재개.

## 오케스트레이터 UI (`orchview.js` · `stepflow.js`)

탭 3: 인시던트 스윔레인(현장·셀·오케스트레이터·실행 자원) · 제어 흐름(STEP 6 × 레인 4) · 명령 콘솔.

STEP: ①혼류 투입 ②분류 분기 ③조립·선반 ④체결 판정 ⑤포장 ⑥적재·출하·FAC.

셀 자체 해결(피지컬AI 자율 재보정)은 결과만 통보. 필터로 숨길 수 있음.

## 상위 명령 (`commands.js`)

셀: ACK → 실행 → 완료 보고. MQTT `…/Commands`에도 상태 발행.

| 구분 | 명령 | 현장 |
|---|---|---|
| 긴급 | 비상정지 | Cat.0. 전체면 이동체·컨베어도 정지. 리셋 전 거부 |
| 긴급 | 보호정지 | Cat.2 감속 정지 |
| 긴급 | 안전 감속 25% | 사이클·이동 25% |
| 긴급 | 이동로봇 대피 | 대기 구역. 해제 후 재개 |
| 긴급 | 비상정지 해제 | 자가진단 5초 후 재가동 |
| 제어 | 사이클 정지/재개, 속도 50–110%, 투입 정지/재개, 재보정, 예방정비 | |

안전: 전체 비상 중 셀 리셋 거부, 전체 보호 중 셀 재개 거부, 정지 셀에 보정·예방 신규 금지. 자동: 무단진입 → 9m 안 감속, 연기 → 최근접 셀 보호정지.

상단 🛑는 전체 비상정지.

## 대화 · 게이트

- **추론 기반**: 내장 에이전트만 운전. Pages 기본.
- **대화 기반**: 같은 에이전트 + 운영자 문장. 내장 해석기 먼저, 실패 시 Claude(`server/llm-agent.mjs`, 도구 루프, 키는 서버만).
- 게이트 5단 (`gate.js`): 해석 → 대상 확인 → 안전 규칙 → 실행 가능성 → 영향 평가. 한 단이라도 실패면 거절+대안. 주의(⚠)는 수행하되 영향 표시.
- 한 번에 여러 지시 가능(쉼표·“그리고”). 모호하면 셀 지정 요구.

Claude는 주기 운전에 안 들어간다. 예전 `agent.llm` 경로는 제거됨.
