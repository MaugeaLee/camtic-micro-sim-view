# 공장 · 라인 · 3단계

OCS 셀 ID(A-3-1~5, 셀당 협동 10·AMR 4·AMMR 1)와 **숫자가 다르다.** 시뮬은 한 Zone에 셀 6개를 두고 혼류한다. 산정 문서의 “완성 기준 5셀 동일 규모”를 이 레이아웃으로 바꾸지 말 것.

## 정밀조립Zone

제품: 도어트림(서연인테크) · e-axle(쉐플러코리아). 이름 `ZONE_NAME`. 레이아웃 `zone`.

```
투입(-28,0) → SORT(-18,0)
                ├ doortrim: DT_ASSY(-5,4.6) → DT_FAST(7,4.6) ─┐
                └ eaxle:    EA_ASSY(-5,-4.6) → EA_FAST(7,-4.6)─┴→ PACK(18,0) → 적재(28,0)
```

| id | no | type | 제품 | 기본 로봇(피지컬AI 레시피) | cycle |
|---|---|---|---|---|---:|
| SORT | 1 | sort | shared | AMMR×2 | 7 |
| DT_ASSY | 2 | assembly | doortrim | cobot×4 | 14 |
| DT_FAST | 3 | screw | doortrim | cobot×2 | 14 |
| EA_ASSY | 4 | assembly | eaxle | cobot×4 | 16 |
| EA_FAST | 5 | fasten | eaxle | articulated×1 | 12 |
| PACK | 6 | pack | shared | AMMR×2 | 8 |

레거시·자동화의 분류·포장은 협동로봇×2. 사이클·로봇 수는 **예시 가정값**.

경로: `ZONE_ROUTES`. 혼류: `ZONE_MIXES` = 1:1 / 2:1 / 1:2 / dt / ea. 투입 순서는 비율 평준화. 한쪽 라인이 막히면 분류셀이 같이 선다.

게이트: 분류·포장 입구. 판별 후 주/보조 로봇 역할이 바뀜. 필드 `GateDecision` · `GateProduct`.

공정 설계 도크는 **레시피**(이름·로봇·대수·사이클)만 변경. 셀 순서·유형은 고정. 자유 배치는 사용자 라인.

## 건물·물류

건물 89m × 40m (생산동 + 왼쪽 물류 확장동 13m, x −51~37.6).

- AMR 16대. 복귀로 z=18.8, 대기 z=17, 출동 z=15.4, 복귀 x=31.2, 투입 진입 x=−30.6. 셀 중앙 정차. Open-RMF 없음.
- 물류 선반 중심 x=−45.2: 서쪽 입고 지게차, 동쪽 AGV·휴머노이드. 원자재 6칸 · 부품 6칸. 재주문점 원자재 80→240, 부품 360→1440.
- 입고 지게차 전용 x −50.8~−46.4 · z −18.6~4.3.
- 구분 적재 구역당 24개(`FG_ZONE_CAP`). AMR이 가운데 정지 구간 진입(1.3초) 후 피킹.
- 출하 지게차 → 도크 1·2 → 트럭 32개(팔레트 4). 레거시 16개 이상, 자동화·피지컬AI 8개마다 출동.

## 3단계 (`MODES`)

| | 레거시 `traditional` | 자동화 `smart` | 피지컬AI `dark` |
|---|---|---|---|
| 셀 간 물류 | 고정 컨베이어 | AMR 16 | AMR 16 |
| 운영 | 작업반장, 안돈 | MES식 단일 에이전트 | FACOS, 혼합형 다중 기본 |
| 지게차 | 유인 | 유인 | 자율 |
| 5G | 없음 | AMR·AGV | 이동 로봇 전부 |
| CCTV AI | 녹화만 | 녹화·관제 | CCTV 에이전트 감지·보고 |
| 뒷벽 화면 | 없음 | CCTV+중앙관제 | +로봇 비전 |
| FAC 전표 | 없음(수기) | 있음 | 있음 |
| 적용된 기본 레버 | `andon: true`, `alarmDelay` 10초 | `amrStage` 2 | `releaseMargin` 0.94, `agentArch` hybrid |

명령 전송 지연(가정): 피지컬AI 0.2초(비상 0.05) · 자동화 0.6(0.3) · 레거시 8(3).

오케스트레이터 판단: 피지컬AI 1.5초 · 자동화 3초 · 레거시 안돈 약 10초.

## 이동체·충돌 (시뮬 규칙)

- 충전 도크는 정지 장애물. 주인은 출입 때만 무시.
- 현장 이벤트 반경: 누유 1.3 · 이물질 1.0 · 연기 1.8 · 무단진입 2.2 (+로봇 크기). 대응 로봇만 진입.
- 지게차는 차체+포크(`FORK`). 트럭 적재 시 포크 1.27m.
- 우선순위 P1 화재·인명 → P5 효율. 선점 후 작업 재개.

## 설비 ID

사람 제외 전 자산에 `assignIds` (`sim.js`). 예: AMR `AM-01…`, 지게차 `FL-R1`, CCTV `CC-01…`, 기지국 `gNB-01…`. AAS 자산 id와 맞춤.

## 사용자 라인

`DEFAULT_LINE`: CNC–용접–도장–비전–포장, 일자형. 스테이션 최대 8, 로봇 최대 4. 유형 카탈로그에 cnc/press/laser/weld/assembly/paint/vision/test/pack/sort/pressfit/screw/fasten. AMMR·휴머노이드는 `darkOnly`.
