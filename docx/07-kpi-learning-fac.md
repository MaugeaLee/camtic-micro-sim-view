# KPI · 학습 · FAC · 보안

수치는 시뮬 시드 평균이다. 현장 실측처럼 쓰지 말 것. 원문 표: `docs/KPI_IMPACT_REPORT.md`.

## KPI 정의 (`impact.js`)

이론 사이클 기준 5.40초 → 이론 UPH 667. **OEE + 원인별 손실 = 100%.**

원인: 고장 · 예지정비 · 재보정 · 결품 · 공급 차질 · 진로 이벤트 · 정지·감속 명령 · 흐름·밸런스 대기 · 사이클 속도 · 품질 불량.

파급 귀속 순서: 공급 차질 → 진로로 멈춘 AMR → 상·하류 정지 → 나머지 흐름 대기. 자재대기는 대기 셀이 아니라 원인에 매김. 가중치 = 셀 실효 사이클 ÷ 병목 사이클.

WIP: 원인별 붙잡힌 대상물 시간평균. POWER: 정지·대기 대기전력 kWh + kWh/개 영향.

## 2시간 × 시드 3 (리포트)

| 단계 | UPH | OEE | WIP | kWh/개 |
|---|---:|---:|---:|---:|
| 레거시 | 327 | 49.0% | 13.8 | 0.26 |
| 자동화 | 389 | 58.4% | 7.7 | 0.18 |
| 피지컬AI(이벤트 12) | 474 | 71.2% | 8.7 | 0.11 |

손실 1위는 세 단계 모두 흐름·밸런스 대기(23–32%p). 레거시만 고장 −11.3%p가 큼. 진로 이벤트 OEE <0.05%p.

이미 코드에 넣은 레버:

| 단계 | 키 | 값 | 실운전 효과(2h×3) |
|---|---|---|---|
| 자동화 | `amrStage` | 2 | UPH 381→414, OEE +5.0%p, WIP 7.7→10.2 |
| 피지컬AI | `releaseMargin` | 0.94 | UPH 473→475, WIP 동일 |
| 레거시 | `andon` + `alarmDelay` | true, 10s | 고장정지 −12%, UPH 321→325 |

예지정비 임계 상향은 피지컬AI에서 UPH 하락 → 보류. 트윈은 새 라인 30분×시드 3, 실측은 적용 시점 상태에서 10분. 점수 = UPH% + ΔOEE − 0.25×WIP% − 0.5×kWh/개%.

의사결정: 1분마다 최근 30분 분석 → 트윈 검증 → 적용/보류/10분 실측/되돌리기.

## VLA (`vla.js`)

대상: 셀 6축/협동/AMMR 15대(사이클 3번에 1번) + 이동 휴머노이드 4대(작업 2번에 1번). 5Hz 관절·TCP·그리퍼 + 카메라. 지시문·성공 라벨·모델 버전.

zip ≈ LeRobot: `meta/info.json`, `episodes.jsonl`, `data/*.jsonl`, `videos/`. ffmpeg면 카메라별 H.264 160×120, `dtype: video`.

학습은 **시뮬**: 에피소드 200개마다 10 에폭 → 검증 +0.3%p → 카나리 40초 → OTA. 버전당 사이클 −1.5% · 불량 −10%, 최대 5단. 실제 역전파 없음.

저장: `POST /api/episodes`, `data/episodes/<로봇>/<run>_<ep>.zip`.

## AIOS (`aios.js`)

10초 샘플, 특징 23종 + 인시던트·의사결정 → 전이(상태→행동→보상). 10분 zip `data/aios/`.

정책 헤드 3개(탐색, 신경망 아님): AMR 선행 배차 1→2(3 이상은 교착) · 절전 진입 25→15→9초 · 판단 지연 1.5→최소 0.8초.

트윈 20분×시드 2, 생산+0.5×에너지 ≥0.5%면 통과. 섀도 60초 → 적용 → 10분 실측, UPH −5%면 롤백.

문서 예: v1.1 배차2+절전15+지연1.15 → 트윈 UPH +21.8%. 이후 후보는 0%라 미배포.

## FAC (`fac.js` · `fac-api.mjs`)

자동화·피지컬AI. 오케스트레이터 결과를 같은 자리 전표로 남김. 외부 ERP 송신 아님. 재고는 시뮬 재고와 일치(확정 전 하차/상차만 차이).

제품: RM-BOX · PT-KIT · FG-DT · FG-EA. 설비 52대 등록.

이벤트: master · po.create · receipt.done · internal.done · production.done · delivery.done · mr.create · mr.update · mr.stage.

화면 2초마다 `POST /api/fac/push`. 조회 GET `/status` `/po` `/moves` `/stock` `/mr` `/equipment` `/orderpoints` `/master` `/events?since=&limit=&type=`. 쓰기 API 없음. 메모리 20000건, 새 run이면 초기화. 서버는 127.0.0.1.

## 보안 (`security.js`)

총괄4 착수보고 4계층을 **기록·시연**으로 재현. 암호 연산 없음.

| 층 | 시뮬 동작 | 자료상 담당 |
|---|---|---|
| 에이전트 | DID/VC 최소 권한, 명령 서명 | 라온시큐어 |
| OT | OTAC·구간암호·DPI, 지연 +33% 가정 | 센스톤·아이티스테이션 |
| 데이터·IP | eVDI·동형암호 연합·ZKML 기록 | 디사일로·서강대·틸론 |
| 모델 | 메타모픽 5종×40 + 차등 테스트 | 전북대 |

위협 버튼 4종 → 차단 → P2 인시던트, 생산 계속. 1차년도 목표 숫자는 창 표시용.
