# 인지 · 통신 (CCTV · 로봇캠 · 5G · 드론)

전부 **디지털트윈 안 계산**이다. 실제 RAN/NVR/YOLO 가중치는 포함하지 않는다.

## CCTV (`cctv.js` · `cctvview.js` · `cctvrec.js`)

배치: 바닥 1m 격자, 설비 LOS 가림 후 탐욕 집합 덮개. 실내 천장 돔 7.5m 반경 9m, 야드 PTZ 반경 20m. CCTV와 5G 기지국은 2.5m 이상 이격.

정밀조립Zone: **45대**(실내 35·입고 6·출하 4), 지점 5943, 사각 0, 이중 감시 77%. 기본 라인 48대. 라인 바꾸면 재계산(~60ms, 캐시).

피지컬AI CCTV 에이전트: 감지·보고·이력만. 대응은 오케스트레이터. 이벤트 2초 안 감지(가정). 로봇이 먼저 보면 “교차 확인”.

오버레이 형식(추론 없음): YOLO11 박스, ByteTrack ID, YOLO11-seg 마스크, D-Fire 연기, 지오펜스. 가리면 미탐지, 거리↑ 신뢰도↓.

전광판 12×4m, 대수에 맞춰 16:9 분할. NVR: 2fps · 2592px · 5분 WebM. Pages는 최근 2구간.

## 로봇 카메라

피지컬AI 기준 약 **70대** 분할 녹화(칸 256×144, 2fps, 5분). 손목/머리/양손/등/전방/짐벌.

정보 창 LIVE ~10fps. 휴머노이드·AMMR은 head·handL·handR·back 탭.

비전 전광판 12×4m, 8분할, 5초 순환. 대응 중 로봇은 📌 고정.

ffmpeg 있으면 구간 MP4 + 카메라별 crop MP4. AAS File `Video`는 카메라별 MP4, 원본은 `SourceVideo`.

## Private 5G (`net5g.js`)

자동화·피지컬AI만. n79 4.75GHz · 100MHz · 30kHz. InF(TR 38.901) 경로손실. 목표 RSRP ≥ −80dBm, 셀 반경 18m.

정밀조립Zone: **기지국 10대**, 음영 0, 최저 RSRP −78.6, 평균 −72.9. PCI = 3×SSS+PSS, 이웃 mod 3 최소화.

UE: 피지컬AI 35대, 자동화 AMR·AGV 19. 100ms RSRP, L3 k=4. A3 +3dB · TTT 160ms · Xn DAPS(끊김 0ms).

지연 모델: 고정 5.9ms + 그랜트 경쟁 + M/M/1 부하. 기지국당 임계 ≈30대(휴머노이드/AMMR만 24). MLB·수락 제어. 일반 운전 최악 p99 7.7ms.

경로(가정): AAS → PubSub JSON → MQTT → NR UL → UPF → 브로커. 문서상 1시간 업링크 유실 0.

## 드론 (`drone.js`)

피지컬AI 3대(H1–H3). 산정: 재방문 p95 ≤120s, 20초 안 도착 ≥95%, 가용 0대 ≤1% → 3대가 최소 충족.

고도 순찰 ~6m, 현장 중계 5.4m. 우선: 현장 이벤트 > 고장 > 결품 > 공급 차질. 배터리 ~24분, 22% 이하 귀환, 무선 충전 ~4분.

드론 관찰은 오케스트레이터 판단 보강·Claude 스냅샷·AIOS 이벤트에 들어감.
